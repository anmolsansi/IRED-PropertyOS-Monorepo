# Completed Engineering Tickets

This folder contains engineering tickets that have passed their full Definition of Done and reviewer approval.

Do not place unfinished work here.

When completing a ticket:

1. Update its metadata to `Status: Completed`.
2. Fill in the Completion Record with the engineer, reviewer, PR, final commit, completion date, and any material notes.
3. Confirm every Acceptance Criteria and Definition of Done checkbox is satisfied.
4. Move the ticket from `../Pending/` into this folder in the implementation PR.

Completed tickets are retained as implementation history and should not be deleted merely because the code has shipped.
